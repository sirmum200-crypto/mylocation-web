            الهدف

              مستند السيرة في القاعدة: cv/mohamed-heidar

              أفضل 5 مواقع استضافة مجانية

              خيارات مجانية ممتازة لنشر الموقع، مع الميزات والعيوب لكل موقع:

              1

              GitHub Pages github.io

              استضافة static مجانية من GitHub مباشرة، وهي التي عليها هذا الموقع الآن.

              • مجاني 100% وبدون بطاقة بنكية
              • نشر تلقائي مع كل push (Actions)
              • نطاقات فرعية لكل مستخدم + دومين مخصص
              • نسخ تاريخ كامل (Git) وتراجع سهل
              • ملفات static فقط (HTML/CSS/JS) — لا Backend ولا PHP
              • محدود بـ 1 GB مساحة و100 GB نقل شهري
              • بلا خادم Node/Express أصلي
              زيارة الموقع
              2

              Netlify netlify.app

              استضافة static مع Forms وServerless Functions ضمن الخطة المجانية.

              • نشر بضغطة زر من GitHub أو بـ netlify deploy
              • Form backend جاهز (Netlify Forms) بدون كود
              • 100 GB نقل شهري + نشرات Previews لكل PR
              • دعم كامل لـ Web Push وRedirects
              • الدومين الفرعي ينتهي بـ .netlify.app
              • الوظائف المجانية محدودة (125K/شهر)
              • البناء يتوقف إذا تجاوز الوقت المجاني
              زيارة الموقع
              3

              Vercel vercel.app

              الأفضل للمشاريع الحديثة (React/Next) مع دومين فرعي فوري لكل push.

              • مجاني وبسرعة نشر فائقة
              • دعم كامل لـ Next.js وSSG
              • 100 GB نقل شهري + دومين فرعي لكل فرع
              • مراجعات Deployment لكل PR
              • المشاريع الـ Serverless محدودة زمنيًا في المجاني
              • الـ Functions تتوقف عند نفاد المدة المجانية
              • متابعة Team features مدفوعة
              زيارة الموقع
              4

              Cloudflare Pages pages.dev

              أسرع شبكة CDN في العالم مع Workers مجاني بجوار موقعك.

              • نشر فوري جدًا + CDN عالمي مجاني
              • 10,000 بناء شهريًا بلا حدود للنقل
              • Workers المجانية 100,000 طلب/يوم
              • دعم كامل لـ Web Analytics وSecurity
              • سقف 20,000 ملف و25 MB إجمالي في الخطة المجانية
              • خاصية Workers Funnel تحتاج نطاقًا مخصصًا
              • Features المتقدمة (Access) مدفوعة
              زيارة الموقع
              5

              Firebase Hosting web.app

              استضافة Google الرسمية، مثالية لمن يستخدم Firestore — وهو ما يعتمد عليه هذا الموقع.

              • تكامل مباشر مع Firestore / Auth / Functions
              • نشر بأمر واحد: firebase deploy
              • CDN عالمي + شهادة SSL مجانية
              • 10 GB مساحة و360 MB نقل/يوم مجانًا
              • الخطة Spark تتوقف عند عدم نشاط المشروع 30 يومًا
              • نقل يومي أقل من Netlify/Vercel
              • الربط بمشروع Google Cloud واحد فقط
